See any language, in place.

Polyglass is a transparent overlay for Windows that reads the text on your screen and draws the translation, in the language you choose, right over it. Spanish, Japanese, English and more. It works on games, videos, apps and web pages, and runs fully offline.

What it does

Translates in place

Each translation is painted over its source line, on a background colour sampled from your screen.

Fully offline

OCR and translation both run on your PC. Nothing is sent anywhere.

Any language, any direction

Pick From and To like Google Translate, or let it detect the language. Ctrl+Alt+D swaps them.

Many languages

Chinese, Japanese, Korean, Russian, Arabic, and Latin-script languages like Spanish, French and German, including stylised game fonts.

Live mode

Re-translates only when the text on screen actually changes, so it stays light on CPU.

Click-through

The overlay never gets in the way. Keep playing or working normally.

Install

  1. Download the ZIP and unzip it.
  2. Double-click Install.bat.
  3. Follow the setup wizard. Choose Translate from (or Detect language) and Translate to. It sets up Python, OCR language packs and offline translation models, and makes a desktop shortcut.

Needs an internet connection for setup and about 3 GB of disk space. If Python 3.10–3.12 is missing, the installer gets it for you.

Use

Start Polyglass, click the window with the text, and press:

Ctrl+Alt+TTranslate the screen once
Ctrl+Alt+LTurn live mode on or off
Ctrl+Alt+DSwap the From and To languages
Ctrl+Alt+CClear the overlay
Ctrl+Alt+QQuit

Run games in windowed or borderless mode. Exclusive fullscreen draws above any overlay.
